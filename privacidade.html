Política de Privacidade — Metricas Canal Dark

Última atualização: 9 de novembro de 2026

Quem usa

O Metricas Canal Dark é um script de uso pessoal, executado apenas no computador do dono dos canais. Ele não é oferecido a outros usuários.

Dados acessados

Com a autorização do próprio dono, pelo login do Google, o app acessa:

  • o endereço de e-mail da conta, para confirmar que é a conta certa;
  • dados e métricas dos canais do YouTube dessa conta (YouTube Data API e YouTube Analytics API);
  • a permissão de enviar vídeos para esses canais (escopo youtube.upload).

Uso e armazenamento

Os dados são usados só para gerar relatórios de desempenho e publicar vídeos nos canais do dono. Os tokens de acesso e os relatórios ficam guardados apenas no computador local do dono. Nada é vendido, compartilhado com terceiros ou enviado a outros servidores além das APIs do Google.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os tokens locais podem ser apagados no próprio computador.
